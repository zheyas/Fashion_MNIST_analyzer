
# Распознавание одежды Fashion MNIST с помощью нейронной сети

## Описание

Графическая утилита на Python для распознавания изображений одежды из набора классов Fashion MNIST с использованием обученной нейронной сети.  
Пользователь может выбрать изображение, получит предсказанный класс (например, "футболка", "сумка", "ботинки" и др.). Также доступна возможность открыть стандартный Paint для создания собственного изображения.

## Возможности

- Загрузка и распознавание изображений (PNG, JPG, JPEG, BMP)
- Автоматическое предсказание класса одежды
- Оповещения об ошибках (нет файла, неподходящее расширение и др.)
- Быстрый запуск приложения через графический интерфейс (Tkinter)
- Интеграция с MS Paint для рисования нового изображения

## Требования

- Python 3.7–3.10
- ОС Windows (MS Paint)  
- Файл обученной модели fashion_mnist_dense.h5  
- Необходимые библиотеки Python:

```
pip install -r requirements.txt
```

> Для работы интерфейса требуется стандартный Paint (mspaint.exe), установленный в Windows.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Поместите файл обученной модели fashion_mnist_dense.h5 в директорию с проектом.
3. Установите зависимости с помощью pip (см. выше).

## Запуск
```
python main.py
```

## Использование

1. Нажмите кнопку "Выбрать файл" и выберите изображение одежды (размер 28x28, оттенки серого, формат: PNG, JPG, JPEG, BMP).
2. Для создания рисунка можно воспользоваться "Создать изображение" (откроется MS Paint).
3. Нажмите "Распознать изображение" – появится окно с предсказанным классом одежды.
4. Если файл неподдерживаемого формата или пуст, появится соответствующее предупреждение.

## Классы, которые может распознавать модель

- футболка
- брюки
- свитер
- платье
- пальто
- туфли
- рубашка
- кроссовки
- сумка
- ботинки

## Возможные трудности

- Файл модели fashion_mnist_dense.h5 отсутствует → программа выдаст предупреждение и завершит работу.
- Изображение не поддерживаемого расширения или пустое → появится информационное сообщение.
- MS Paint не установлен → невозможен запуск рисовалки из приложения.

## Примечания

- Программа предназначена для учебных целей.
- Изображения для корректной работы должны быть размером 28x28 пикселей, градации серого (GrayScale).  
- Модель должна быть обучена на датасете Fashion MNIST и сохранена в формате H5 с теми же классами.
